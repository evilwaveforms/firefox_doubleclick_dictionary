# Privacy Policy

Effective: 6 September 2026

Double-click Dictionary performs dictionary lookups without sending the selected word itself. When automatic language selection is enabled, the extension reads the nearest HTML language declaration or uses Firefox's built-in language detector on up to 1,000 characters of nearby text. Language detection happens locally. The extension uses the selected word and language locally to determine which dictionary shard to request. The request does not include the word, page URL, or surrounding page content.

The dictionary is hosted using Cloudflare. As with any network request, Cloudflare receives the requested shard URL, your IP address, and standard HTTP request metadata. This information is processed according to [Cloudflare's Privacy Policy](https://www.cloudflare.com/privacypolicy/). Double-click Dictionary does not use application-level request logging, analytics, advertising, user accounts, or tracking, and does not sell user data.

Your theme and lookup language preferences are stored locally by Firefox. The extension temporarily caches up to 128 lookup results in memory. It does not write lookup history to persistent storage, and the cache is discarded when Firefox terminates the extension's background process.

Definition popups contain an optional link to the corresponding Wiktionary page. Opening that link is a direct visit to Wikimedia and is subject to the [Wikimedia Foundation Privacy Policy](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy).

This policy will be updated if the extension's data handling changes.
